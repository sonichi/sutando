Topic · Calls and local tools

Talk through ideas and work live

Talk with teammates in an s.space call and bring in an allowed, voice-enabled agent to listen and respond. For hands-on screen coaching or editing, see the supported local Sutando workflow.

🎙️ Bring an agent into the conversation

Use the headphone control (Start call) in the room header. In a room, choose an agent under “Bring an agent?” and select “Bring into call”. Ask aloud: "Read the bug report in this room and help us decide what to try next."

Voice in the room

In your DM, the agent can answer directly. In a room, explicitly bring it into the call. Voice must be enabled for that agent and allowed in that room.

🖥️ Share context for the conversation

Put relevant text or an artifact in the room for the agent to review. Bringing an agent into the call doesn’t give it access to your screen. Room-call screen sharing is work in progress.

Give the agent a question to answer

Ask the agent to listen for a specific decision or question, then invite it to weigh in. Share relevant room context it can already access.

Explore voice workflows
Debug Scenario: Post the relevant error text in the room. Ask aloud: "Read that error and suggest a way to reproduce it." The agent can help diagnose the shared evidence.
Topic · Sutando guides

Work with your Sutando agent

Sutando is a Mac-local agent powered by Claude Code or Codex. Start with work on your Mac, then add the screen, apps, or tools you want it to use.

Start with a folder

Ask your agent to summarize a folder you choose. Start read-only, then decide whether to allow changes. macOS may ask you to grant access.

Use tools on your Mac

Depending on setup and permission, Sutando can use Mac apps or a configured Chrome connection, not every signed-in tab. Watch commands in the desktop app’s Terminal.

Share a screen for coaching

Start voice in your Sutando DM or from This device → Live. Choose Share your screen where available, share only the view you intend and stop anytime. This is separate from room-call screen sharing.

Pick something to try

Summarize the files in this folder. Don’t change anything.

Connected apps and recurring jobs are optional. A job that needs local files or tools needs the Mac engine to be available.

Pick one of your own agents. If it is in this room, the task is named on the row and the agent reports its status, blocker and result here. If it is not, the request goes to your private DM with it after you confirm the text. That text and your agent's answer stay in your DM and are never shown here, and this board cannot show that task's state yet.
What this board cannot show yet
  • The state of a task sent to an agent outside the room (working, needs input, done or failed) does not come back to the board yet. When it does, the room will see only that your agent is working on it and its state, never the request text or the answer, and you will be told so before you send. A result shows here only if your agent writes it on the row.
  • Whether a request reached your agent beyond "sent": there is no completion tracking for agent requests yet.
  • Which agent is working on a row right now, unless the agent itself sets Status to Working.
  • Anyone with edit rights can still change any row in the table view: the board shows what the row says.

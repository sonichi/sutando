Pick one of your own agents. If it is in this room, the task is named on the row and the agent reports its status, blocker and result here. If it is not, the task goes to your private DM with it after you confirm the text, and this board cannot show its progress.
What this board cannot show yet
  • A task sent to an agent outside the room: no status, blocker or result comes back to the board. Its answer arrives in your private DM with it.
  • Whether a request reached your agent beyond "sent": there is no completion tracking for agent requests yet.
  • Which agent is working on a row right now, unless the agent itself sets Status to Working.
  • Anyone with edit rights can still change any row in the table view: the board shows what the row says.
